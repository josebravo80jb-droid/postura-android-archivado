# Postura — App Android de Fusión de Sensores (ARCHIVADA)

> App Android nativa que mide la inclinación del móvil mientras lo sostienes.
> **Objetivo original:** recordatorio de postura cervical.
> **Objetivo real:** mide la muñeca, no el cuello. Limitación física, no de código.

## Por qué está archivada

El móvil en la mano no puede medir la postura cervical. Es física, no código.
Elegí archivar el proyecto en lugar de publicarlo mintiendo al usuario.

## Qué demuestra técnicamente

- Fusión de sensores Android con triple fallback
- Foreground Service specialUse (Android 14+)
- DataStore + Room + Compose
- Arquitectura limpia sin sobre-ingeniería
- Tests unitarios con lógica desacoplada

## Stack

Kotlin · Jetpack Compose · DataStore · Room · KSP · Android SDK 34+
